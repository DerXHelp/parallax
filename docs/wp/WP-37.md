### Anforderungen (normativ)
1. **Slash-Menü:** öffnet, wenn der Entwurf mit `/` beginnt und der Cursor im ersten Wort steht.
   Quellen: native Parallax-Befehle (Tabelle unten), `detail.commands` (Name, Beschreibung,
   `argumentHint`, Aliase; Kennzeichnung „Claude Code“ bei `builtin`, sonst „Skill/Befehl“, `mcp__…`
   als MCP), ohne Katalog `init.slashCommands` nur mit Namen. Ausgeblendet: Terminal-Befehle (Punkt 3).
   Fuzzy (`fuzzyFilter` über Name + Aliase + Beschreibung), Pfeile, Tab/Enter übernimmt `/<name> `
   (mit Argument-Hinweis als Platzhalter) bzw. führt native Befehle ohne Argument sofort aus, Esc
   schließt. Nicht im Menü bei offener Entscheidung mit Ziel-Sperre (ADR-040 bleibt unberührt).
2. **Senden eines `/`-Entwurfs** (Enter): erstes Wort = Befehl (Aliase aufgelöst), Rest = Argument.
   | Befehl | Wirkung |
   |---|---|
   | `/model [name]` | ohne: Modell-Picker öffnen; mit: `session.setModel` (Name per `modelNameSchema`, sonst Inline-Fehler) |
   | `/effort [low…max]` | ohne: Effort-Untermenü; mit: `session.setEffort` |
   | `/fast [on\|off]` | ohne: umschalten; mit: setzen (`session.setFastMode`); nur wenn das Modell `supportsFastMode` |
   | `/plan [text]` | `session.setPermissionMode('plan')`, mit Text danach den Text senden |
   | `/rename [name]` | mit: `session.rename`; ohne: `requestShell({kind:'renameTitle'})` |
   | `/status` | `requestShell({kind:'sessionInfo'})` |
   | `/resume` | `requestShell({kind:'conversations'})` |
   | `/help` | Dialog im Composer: native Befehle, Katalog gruppiert, Link „Tastenkürzel“ (`?`) |
   | `/clear` (Aliase `reset`, `new`) | durchreichen (Engine macht den Reset im selben Eintrag) |
   | Terminal-Befehl | nicht senden; Hinweis „Nur im Terminal verfügbar“ mit Aktion „In externer Konsole öffnen“ (`session.openExternal`, Fehler als Hinweis) |
   | alles andere | als Prompt `"/name args"` senden (wie bisher, Queue/Priorität unverändert) |
   Ein nativer Befehl leert den Entwurf nur bei Erfolg.
3. **Terminal-Befehle** = `init.terminalSlashCommands` ∪ statische Liste: `theme`, `terminal-setup`,
   `tui`, `vim`, `keybindings`, `statusline`, `ide`, `desktop`, `bg`, `voice`, `mobile`,
   `install-github-app`, `install-slack-app`, `upgrade`, `exit`, `quit`, `login`, `logout`,
   `permissions`, `hooks`, `memory`, `plugin`, `mcp`, `agents`, `remote-control`; `config` nur ohne
   `key=value`-Argument.
4. **Screenshots (ADR-103):** Einfügen (`clipboardData` Bild-Items), Ziehen (Dateien), Büroklammer
   (`<input type=file accept=…>`); nur `ATTACHMENT_MEDIA_TYPES`, sonst Hinweis „Nur Bilder“;
   höchstens `LIMITS.attachmentsMax`. Verkleinern im Client (`createImageBitmap` + Canvas): lange Kante
   ≤ `LIMITS.imageMaxEdgePx`, PNG; ist das Ergebnis > `LIMITS.imageBytes`, JPEG mit Qualität 0,9 →
   0,8 → 0,7, sonst Fehlerhinweis; GIF unverändert, wenn klein genug. Sofortiger Upload
   (`fetch(API_PATHS.attachments + '?name=…&width=…&height=…', {method:'POST', body: blob,
   headers:{'Content-Type': type}, credentials:'same-origin'})`, Antwort per
   `attachmentUploadResponseSchema`, Fehler per `errorPayloadSchema` + `tError`). Chips über dem
   Eingabefeld (Vorschau per Objekt-URL, Name, Fortschritt/Fehler, Entfernen per Knopf und
   Entf/Backspace bei Fokus). Senden wartet auf laufende Uploads (Knopf deaktiviert) und schickt
   `attachments: [{blobId}]`; Text darf leer sein. Entwürfe speichern nur den Text (Chips gehen beim
   Neuladen verloren – Hinweis nicht nötig).
5. **Ghost-Text (ADR-117):** leerer Entwurf + `detail.promptSuggestion` → Platzhalter mit dem
   Vorschlag, Tab übernimmt; sonst normaler Platzhalter.
6. **Rate-Limit-Banner (ADR-112)** über dem Eingabefeld, solange `rateLimitedUntil` in der Zukunft
   liegt: „Nutzungslimit erreicht – zurückgesetzt um HH:MM“ + „Fortsetzen um HH:MM“
   (`session.continueAfterLimit{enabled:true}`); geplant (`wakeupAt`) → „Fortsetzen geplant um HH:MM“
   + „Abbrechen“; nach Ablauf ohne Plan „Fortsetzen“ (sofort).
7. **Deaktivierter Composer:** `summary.archived` oder `summary.external !== null` → kein Eingabefeld,
   nur eine knappe Zeile (die Aktionen zeigt das Pane-Banner von WP-35).
8. **Transkript:** `ui/lightbox.tsx` (Dialog, Bild einpassen/100 %, Mausrad/Knöpfe zoomen, Esc,
   „Speichern unter“ als `<a href=blobPath download=name>`); Klick auf Tool-Ergebnis-Bilder und
   Anhang-Vorschauen öffnet sie. System-Zeile `handoff` (`external`: „In externer Konsole geöffnet“,
   `returned`: „Aus der Konsole zurück – n Einträge übernommen“). V2-12: im Fließtext bleibt der
   Backslash in Windows-Pfaden (`[A-Za-z]:\…` bis zum nächsten Leerzeichen) vor Satzzeichen erhalten;
   sonst unverändertes Markdown (Tests mit Gegenproben `\*`, `\_` außerhalb von Pfaden).
9. **i18n:** Texte nur in `composer` bzw. `transcript`.
10. **Playground:** Slash-Menü (mit/ohne Katalog, Terminal-Hinweis), Chips (Upload ok/Fehler),
    Ghost-Text, Rate-Limit-Banner (drei Zustände), deaktiviert, Lightbox, `handoff`-Zeilen.

### 2.2 Verhalten (Präzisierungen und Abweichungen)

- **Slash-Menü:** offen, solange der Entwurf mit `/` beginnt, der Cursor im ersten Wort steht, es
  Treffer gibt und keine Entscheidung das Enter-Ziel ist (ADR-040). Reihenfolge: native Befehle,
  dann Katalog (`detail.commands`), ohne Katalog die Namen aus `init.slashCommands` (Art `plain`, ohne
  Badge). Ein Katalog-Eintrag mit nativem Namen (`model` der CLI) verschmilzt mit dem nativen (Aliase
  bleiben). `mcp__…` → „MCP“, `builtin` → „Claude Code“, sonst „Skill/Befehl“. Esc schließt nur das
  Menü (Stopp-Kürzel sieht die behandelte Taste), Blur schließt, Fokus/neues Wort öffnet wieder.
  Tab/Enter/Klick: native Befehle ohne Argument (`/status`, `/help`, `/resume`) laufen sofort, alle
  anderen werden als `/<name> ` eingesetzt; danach steht der Argument-Hinweis als Geisterschrift
  hinter dem Cursor (auch vorgelesen per `aria-describedby`). Enter bei offenem Menü übernimmt also
  auch einen vollständig getippten Durchreich-Befehl erst – das zweite Enter sendet (wie gefordert).
- **Senden:** `classifySlash` prüft zuerst Terminal-Befehle, löst dann Aliase auf; **`/config` und
  seine Aliase** (z. B. `/settings`) sind ohne `key=value` Terminal-Befehle, mit `key=value` gehen sie
  als `/config …` durch. Aliase von Katalog-Befehlen werden als Befehlsname gesendet (`/new x` →
  `/clear x`). Der Sendeknopf heißt bei nativen/Terminal-Entwürfen „Ausführen“; „Jetzt senden“
  entfällt dann.
- **Native Befehle** (Entwurf weg nur bei Erfolg, und nur wenn er sich inzwischen nicht geändert
  hat): `/model default` → `setModel(null)`; `/effort default|auto` → `setEffort(null)`; `/effort` ohne
  Stufe bei einem Modell ohne Aufwand → Inline-Fehler; `/fast` akzeptiert `on|off|true|false|1|0`;
  `/plan text` wechselt nur, wenn der Modus nicht schon `plan` ist, und sendet den Text dann wie eine
  normale Nachricht (mit fertigen Anhängen); `/rename` prüft `LIMITS.titleChars`; nimmt niemand eine
  Shell-Anfrage an (`requestShell` = false), steht „/x ist hier nicht verfügbar“ unter dem Feld.
  Server-Fehler → Hinweis (`showErrorNotice`), Entwurf bleibt.
- **Terminal-Hinweis:** `Alert` über dem Feld mit „In externer Konsole öffnen“ (`session.openExternal`;
  Fehler als Hinweis, Entwurf bleibt) und „Hinweis schließen“; Tippen schließt ihn ebenfalls.
- **Bilder:** nur für Sessions des eigenen Hosts (`LOCAL_HOST_ID`; ein entfernter Host könnte den Blob
  nicht auflösen). Einfügen nur, wenn die Zwischenablage **keinen** Text hat (Word/Excel legen neben
  Text ein Bild ab). Verkleinern wie gefordert; zusätzlich bleibt jedes Bild unverändert, das weder
  skaliert noch kleiner werden muss (kein Umkodieren eines kleinen JPEG in ein größeres PNG); JPEG
  bekommt weißen Hintergrund (Transparenz würde schwarz). Der Name folgt dem Format (`x.png` →
  `x.jpg`), im Upload-Query auf 260 Zeichen gekürzt. **Fortschritt** = Zustand je Chip („Wird
  vorbereitet…“, „Wird hochgeladen…“ mit Spinner, „Bereit“, Fehlertext) – `fetch` meldet keinen
  Upload-Fortschritt in Prozent. Fehlgeschlagene Chips blockieren das Senden („Entferne das
  fehlgeschlagene Bild“). Entfernen bricht einen laufenden Upload ab (`AbortController`). Ein
  fehlgeschlagenes Senden stellt Text und Chips wieder her. Chips bleiben je Session im Speicher
  (Sessionwechsel), nicht über ein Neuladen.
- **Ghost-Text:** Platzhalter = Vorschlag + `Tab`-Kbd; Tab übernimmt nur bei leerem Feld, sonst
  verlässt Tab das Feld wie üblich; nie bei einer Entscheidung als Enter-Ziel.
- **Rate-Limit-Banner:** `limited` / `scheduled` (`wakeupAt` in der Zukunft) / `expired`; `expired`
  endet mit dem ersten Turn nach dem Reset (`lastTurn.endedAt > rateLimitedUntil`) und wird während
  `working`/`starting`/`external` nicht gezeigt. Liegt der Zeitpunkt > 24 h entfernt (Wochenlimit),
  zeigt es Datum + Uhrzeit. Neu gerendert nur an den Fristen (`useNowUntil`).
- **Deaktiviert:** `archived` bzw. `external !== null` → eine Zeile mit Symbol, kein Feld; der Entwurf
  bleibt gespeichert und ist nach dem Zurückholen wieder da.
- **Lightbox im Transkript:** Eine `TranscriptView` hat **eine** Lightbox neben der virtualisierten
  Liste (`ImageViewer`). Grund: virtua hängt Zeilen außerhalb des Sichtbereichs aus; folgt die Liste
  neuer Ausgabe, wäre eine Lightbox in der Zeile mitten im Betrachten verschwunden. Fokus nach dem
  Schließen: zurück zum Vorschaubild, ist dessen Zeile weg, auf die Transkript-Region. Außerhalb einer
  `TranscriptView` (Tests, andere Einbettungen) bringt `ImageThumb` eine eigene Lightbox mit.
  „Speichern unter“ = `<a href="/api/blob/<id>" download="<name>">`; ohne Namen
  `image-<12 Zeichen der ID>.<Endung>`. Hintergrund `bg-background/90` + leichte Unschärfe (der
  Dialog-Overlay-Token war für ein Bild zu durchscheinend). „In Ordner zeigen“ (Plan) bleibt Phase 3.
- **`handoff`:** `external` „In externer Konsole geöffnet“, `returned` „Aus der Konsole zurück – n
  Einträge übernommen“; bei 0 übernommenen Einträgen eigener Text „keine neuen Einträge übernommen“
  (Fallback L7); jeweils mit Uhrzeit, Symbol Konsole bzw. Rückkehr-Pfeil.
- **V2-12:** vor dem Parsen werden in Fließtext-Zeilen alle Backslashes eines Laufwerkspfads
  (`X:\…` bis zum Leerzeichen, nicht mitten im Wort) verdoppelt, die vor ASCII-Satzzeichen stehen
  oder den Pfad beenden. Unverändert bleiben Code-Spans (Backtick-Läufe gleicher Länge, maskierte
  Backticks öffnen keinen), umzäunter Code (``` und ~~~), eingerückte Zeilen und Escapes außerhalb
  von Pfaden (`\*`, `\_`).

### 2.3 Entscheidungen

1. **Eine Lightbox je Transkript** statt je Vorschaubild (siehe 2.2) – das Primitive kann dafür
   ohne Trigger gesteuert werden; der Fokus kehrt per `onCloseAutoFocus` zurück.
2. **Bild-Upload über `fetch`** (kein XHR): Fortschritt als Zustand, nicht in Prozent; Uploader
   austauschbar (Playground ohne Server, Tests).
3. **Native Befehle nur im Client** (`lib/native.ts`, rein über `sendCommand`/`requestShell`); der
   Katalog bestimmt nur Menü und Aliase – ein CLI-Eintrag mit nativem Namen wird nie durchgereicht.
