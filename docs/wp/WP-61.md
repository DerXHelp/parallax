### Rahmen (verbindlich, sonst stoppen und melden)
- Abo-Login über das installierte `claude` (`apiKeySource: none`), **kein** API-Key, Modell `haiku`
  (auch im Plan-Modus; die Fixtures von SDK-0.3.322 sind so entstanden), Mini-Prompts, Budget ≤ 1 USD
  (aus `turn_result`-Kosten summiert; Abo-5h-Fenster vorher/nachher notieren).
- Scratch-Ordner `%TEMP%\parallax-live3-<stamp>\` (Projekte `p1` = Git-Repo mit einigen Dateien inkl.
  Leerzeichen/Umlaut im Namen, `p2` ohne Git, `p3`), Temp-Home `%TEMP%\parallax-live3-<stamp>\home`.
  Das echte `%LOCALAPPDATA%\Parallax` wird nicht angefasst.
- Bei Auth-Fehler, `credits_required`, `rejected`, unerwarteten Kosten: sofort stoppen.
- **Keine Desktop-Bedienung** (Nutzer-Regel 18.10.2026): keine Klicks/Tastatur/Fenster-Fokus/
  Bildschirmfotos des Desktops/UI-Automation per Skript. UI nur über Playwright bzw. die App-API;
  alles Sichtbare außerhalb des Browsers (Notepad++, Explorer, Chrome-PDF-Fenster) prüft der Nutzer
  über die Checkliste unten (vorbereiten, nicht selbst ausführen).
- Externe Programme werden in diesem Paket **nicht** durch den Agenten gestartet (der Server läuft mit
  SDK-Backend; „Im Editor öffnen“/„Explorer“ nur in der Nutzer-Checkliste).
