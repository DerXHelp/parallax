### Verdrahtung (normativ)
1. **Server (`compose.ts`):**
   - `createAttachmentFileStore(home, blobs)` (WP-53) → `EngineStores.attachments` (WP-51).
   - `createFileService({home, entries, transcripts, attachments, settings, …})` (WP-53):
     `entries.entry(entryId)` aus Registry (`cwd`, `conversations`) und Profil (`parseProfileArgs` →
     `additionalDirectories`; Profil fehlt → `[]`); `settings: () => aktuelle Settings`.
   - `hostCommands: [..., fileService.commands]`.
   - Abgriff: der an den Manager übergebene `SessionPublisher` ruft vor jedem `publishOps(entryId, ops)`
     `fileService.observeOps(entryId, ops)` (Fehler dort nur loggen, nie den Hub blockieren).
   - `http/app.ts`-Option `files: fileService` (Route `GET`/`HEAD /api/file`).
   - Beenden: `fileService.flush()` vor den Stores (Reihenfolge §3.3).
2. **Web (`App.tsx`):** Slots `PlanPanel: PlanSidePanel` (bleibt), `...FILES_SLOTS` (`FileLink`,
   `FilePanel`, `FilesPanel`), `...TASKS_SLOTS` (`TasksPanel`, `TaskStrip`); alle Lazy-Slots (bestehende
   und neue) in `SlotBoundary` (WP-58). Fehlende Registrierungen von Anfrage-Handlern (`openFile`,
   `sidePanel`, `attachFiles`) sind Integrationsfehler.
3. **FIX-E2E-EDGE157:** `e2e/live` `chooseManualMode` auf `chooseMenuItem` umstellen (ohne Live-Lauf).

### E2E (normativ; Chrome, FakeBackend, je Spec eigenes Temp-Home und Temp-Projekt)
1. **Viewer:** `fake:files` → Verweise im Text und in Tool-Karten klickbar; Markdown gerendert/roh,
   Code mit Sprung zu `:12` (Zeile markiert), Bild, **PDF im `<iframe>`** (Antwort-Header
   `FILE_PDF_CSP` + `X-Frame-Options: SAMEORIGIN`, Frame lädt ohne Download – L10), gekürzter Text;
   Live: Datei auf der Platte ändern → Viewer zeigt den neuen Inhalt ≤ 3 s.
2. **Guard (L16):** Requests der Seite auf `/api/file` tragen `Sec-Fetch-Site: same-origin` (per
   `page.on('request')`/Route-Mitschnitt); ein `fetch` aus einer Seite auf einem anderen Port wird
   abgelehnt; direkter Aufruf ohne Header → 403.
3. **UNC (L15):** `fake:files`-Antwort mit `\\fake-host\share\x.txt` → kein Link, kein Befehl,
   keine Anfrage an `/api/file` (Mitschnitt), Server-Log ohne fs-Zugriff auf den Pfad.
4. **Dateien-Panel:** listet gelesene/geschriebene/bearbeitete Dateien inkl. Plan und Task-Ausgabe;
   Klick öffnet den Viewer.
5. **Plan:** `fake:plan` → Plan-Tab zeigt den Text schon während des Schreibens, danach die Datei; v1 →
   Feedback → v2 mit Diff; „Mit frischem Kontext umsetzen“ → neue Unterhaltung (Op/Ansicht), erster
   Prompt beginnt mit `Implement the following approved plan.`, Antwort des Fakes; Split-Button merkt
   die Wahl über Neuladen; „Plan“ in der Kopfzeile nach der Freigabe.
6. **Tasks:** `fake:background` → Task-Panel zeigt den Agent mit Zusammenfassung, Stop beendet ihn
   (Status `stopped`); Stop im Composer während eines Turns beendet den Turn, der Hintergrund-Agent
   läuft weiter; `fake:todo` → Aufgabenleiste über dem Composer.
7. **Anhänge:** PDF und `.xlsx`-Datei anhängen (Büroklammer und Drop über dem Transkript) → Antwort
   „Fake: received 1 document(s), 1 file(s)“, Datei liegt im Anhangordner des Temp-Homes;
   großer Paste → Chip, gesendet als `inline_pastes` („Fake: received 1 paste(s)“); `@`-Picker
   (Temp-Projekt als Git-Repo und ohne Git) fügt `@pfad` ein.
8. **Editor/Explorer:** Einstellungen „Dateien“ speichern einen eigenen Editor; „Im Editor öffnen“ und
   „Ordner im Explorer öffnen“ lösen den Befehl aus – **ohne** echten Programmstart: mit
   FakeBackend verdrahtet `compose.ts` immer den aufzeichnenden Fake-Spawn aus WP-53 (Log-Zeile
   `file.open (fake): <ziel> <pfad>`, keine Prozesse; gilt auch für `pnpm dev` und V4); geprüft über
   das Server-Log bzw. einen Test-Endpunkt nur im Fake-Modus, falls vorhanden.
9. **Schmales Fenster:** Viewport 1000 und 800 px: Panel als Überlagerung, Sidebar eingeklappt.
10. **Fehler:** `fake:writes-lost` → Fehlerzeile; Lazy-Slot-Fehler (Chunk-Route blockiert) zeigt die
    `SlotBoundary`-Karte, Rest bedienbar.
11. **Bundle-Budget:** `pnpm build` vorher/nachher (Basis `109c073`): Start-Chunk `index` wächst um
    ≤ 10 kB, neue Bereiche als eigene Chunks (Werte im Ergebnis).
Bestehende 45 E2E-Fälle bleiben grün; keine festen Wartezeiten (Menü-Helfer aus FIX-E2E-EDGE157).
