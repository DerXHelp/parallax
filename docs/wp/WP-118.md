## 3. Entscheidungen
- **Slots per `import.meta.glob`:** Der Playground lädt Feature-Slots nur aus `features/*/playground.tsx`; ein
  statischer Import von `features/changes` bzw. `features/search` verstößt gegen die ESLint-Regel „keine Features im
  Kern“. `showcase/slots.ts` holt `CHANGES_SLOTS` und `SEARCH_SLOTS` per Glob, `demos.tsx` legt sie mit einem
  verschachtelten `FeatureSlotsProvider` dazu.
- **Zoom 85 %, Sidebar 336 px** (statt 90 % und 288 px): Bei 90 % schnitt die Seitenleiste „Ungelesen“ ab, eine
  breitere Leiste kürzte dafür die Kopfzeile. Mit 85 % und 336 px passt beides – auch mit offenem Seitenpanel.
- **Worktree-Branch `multi-filter`:** Parallax benennt den Ordner nach dem Branch (`/` → `-`); ein kurzer Name hält
  die Kopfzeile frei.

## 4. Stolpersteine
- Git Bash + Python-Heredoc halbiert Backslashes (`\\` → `\`, `\\n` → Zeilenumbruch); Ersetzungen mit Backslashes
  oder `\n` mit dem Edit-Werkzeug machen.
- PowerShell macht aus `--only=a,b` eine Liste; die Option in Anführungszeichen setzen (`'--only=review,search'`).
- Suchtreffer und Kommentare zeigen nur den Anfang ihrer Zeile – das Suchwort früh in den Text, den gesendeten
  Kommentar oben in die Datei (sonst unterhalb der Falz).
- Diff-Zeilen über etwa 60 Zeichen brechen im Seitenpanel um; die Beispiel-Patches sind entsprechend kurz.
- Vite meldet beim Screenshot-Lauf „ResizeObserver loop completed with undelivered notifications“ – harmlos, kein
  Fehler-Overlay im Bild.
- `scripts/README.md` (Koordinator) nennt im Abschnitt `scripts/screenshots.ts` noch nur `{overview,plan,files}`.
