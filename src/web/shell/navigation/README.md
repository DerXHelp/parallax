# src/web/shell/navigation – Navigation (Phase 2)

Owner: **WP-35** (Fix-Runde R4: F2, `docs/wp/FIX-R4-F2.md`), Phase 3: **WP-58** („Ordner im
Explorer öffnen“, Texte der Kopfzeilen-Knöpfe, Leiste, Drop-Zone, Slot-Fehlergrenze); WP-63
(„Aus Parallax entfernen…“, „Archiv aufräumen…“, Effort und Context-Regel in der Zeile, weitere
Limit-Fenster); WP-65 (Zeile unter dem Namen, „Titel neu erzeugen“, Reset im Limit-Tooltip); WP-66 („Kurz fragen…“);
WP-67 (Session-Info mit Reitern, `session-info/`); WP-71 („Was läuft wo“: Zähler und Puls in der Zeile).
Auftrag und Ergebnis: `docs/wp/WP-35.md`, `docs/wp/WP-58.md`, `docs/wp/WP-63.md`, `docs/wp/WP-65.md`,
`docs/wp/WP-66.md`, `docs/wp/WP-67.md`, `docs/wp/WP-71.md`.

Bausteine von Sidebar (flach/gruppiert, zweizeilig, Archiv), Quick-Switcher (Strg+K),
Kontextmenüs, Inline-Umbenennen, Kopfzeilen-Menü (Frühere Unterhaltungen, Session-Info, externe
Konsole) und Abo-Limit-Anzeige. Handler des Anfragekanals (`../requests.ts`), registriert von
`NavigationLayer`, solange die Shell steht: `renameTitle`, `conversations`, `sessionInfo`,
`quickSwitcher` (Rückgabe `false` für unbekannte Sessions). Dialoge ohne Trigger geben den Fokus
beim Schließen zurück (`useReturnFocus` aus `src/web/lib/return-focus.ts`, R4W-04).
